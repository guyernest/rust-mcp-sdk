1. `validate_authorization_response(<arbitrary query string>, &record)` over a record built from fixed

   comparison — decode with `url::form_urlencoded::parse` in the target itself — so the target can
   detect a rule defect the crate shares with a restated mirror. Phase 115 measured that a fence which
   restates the code's own rule cannot see a rule defect.

   the list is non-empty and every element parses as an absolute URL.
