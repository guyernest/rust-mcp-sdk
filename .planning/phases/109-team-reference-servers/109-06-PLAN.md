<objective>
Implement the in-process small-team wiring API (D-01): a `TeamRuntime` that, given a `TeamPackage`, calls `derive_attachment` (D-05) and wires exactly the attached servers (team-mcp iff members≥2, approval-mcp iff human_roles non-empty, plus opt-in team-fs/mem-mcp from `built_in_servers` — D-06) together with the member `AgentServer` instances, all in one tokio runtime over in-memory `DuplexTransport` pairs (no sockets — D-04, deterministic + CI-sandbox safe). Member agents get their LLM via the SHARED `team::member::resolve_member_factory` helper — resolving the member's `AgentPackage` llm `ConfigSlot` through `SlotResolver` (D-15) — the SAME single member-LLM construction path the team-mcp dev binary uses (109-05 Task 3), so laptop dev binary and TeamRuntime never diverge. Prove "small team, one process" with an integration test on `FixedSource`, including the team-of-one degenerate case.

Purpose: This is the library the Phase 110 `cargo pmcp team dev` CLI becomes a thin wrapper over — one definition format (TeamPackage) from laptop to platform — sharing member-LLM resolution with the reference dev binary.
Output: `src/compose/wiring.rs` + `tests/small_team.rs`.
</objective>
