<objective>
Implement the team-fs reference server (TEAM-02): a `TeamFsBackend` object-safe async trait (the TaskStore backend-seam model) with 11 `fs__*` operations, a `LocalDirBackend` dev impl backed by a real workspace directory plus a sibling `review/` directory (D-09), `file://` download URLs (D-08), and hard path-traversal containment (security V5). Output: `src/fs/{backend,local,server}.rs`, `src/bin/team_fs.rs`, and the filled `fuzz/fuzz_targets/fs_resolve.rs`.
