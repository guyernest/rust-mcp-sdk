<objective>
Finish the layer set the tracer proved: wire the optional OpenAPI spec layer, make the
0.1.x refusal explicit, and harden the media-type index that replaced positional reads.

Purpose: the tracer landed the config layer and the binary-mode enum on one path. PKG-01
also requires the spec (`london-tube-api.yaml`) to be a first-class layer, and D-11's move
away from positional reads introduces two new failure modes — a duplicate media type
shadowing the real layer, and a 0.1.x envelope silently losing its `binary_ref` because
`ServerEnvelope` has no `deny_unknown_fields`.

Output: an optional, byte-verbatim spec layer with its filename annotation; `detect_legacy_shape`;
duplicate/both/neither layer rejections; the D-11 permutation property test; doctest
examples for both `BinaryMode` arms; and `detect_kind` extended so `cargo pmcp package inspect`
does not silently regress on a config-only package.
</objective>
