  method-or-name mismatch on the v2 path. HTTP status 400.

  capability the client did not declare in `_meta.clientCapabilities`. HTTP status 400.

  `{"sampling": {}}`), never an array — state that in the doc comment.

  the server's accept-list; carries a `supported` list. HTTP status 400.

mapper has a single documented source. Note explicitly in the `-32021` doc that this is a
