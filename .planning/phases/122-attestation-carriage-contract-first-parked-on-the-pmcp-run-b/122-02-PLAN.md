<objective>
The tracer: prove the whole attestation carriage path end-to-end on one thin slice before expanding it. Attestation bytes attach at `pack_server`, travel as an OPAQUE layer whose metadata rides in the layer descriptor's annotations, come back out of `unpack_server` byte-identical, and are rendered by `cargo pmcp package inspect` — all offline, all from a fixture.

This is the phase's architectural risk in one commit: if the optional-layer-plus-annotation shape is wrong (wrong annotation scope, wrong media type spelling, a digest that cannot be compared), it is wrong here, after one task, not after four plans of layered work.

Purpose: land D-01 (6th optional positional parameter), D-04 (metadata in descriptor annotations), D-05 (suffix-free media type) and D-14 (absence is the layer's absence) as one mechanism, and pin D-01's accepted two-digest consequence with a test rather than leaving it as a side effect.
Output: one new media type, three annotation-key constants, one new pack-side type and helper, one new unpack-side type and field, attestation rendering in `inspect`, and every `pack_server` call site in the repo updated.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| untrusted `.pmcp` layout on disk -> `unpack_server` | Blob bytes, layer media types and descriptor annotation values are all attacker-controlled |
| pmcp.run (attestation issuer) -> `pack_server` caller | The attestation payload arrives from outside this repo and is never validated here |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
