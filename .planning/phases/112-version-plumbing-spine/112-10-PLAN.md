The crate-private routing seam (`parse_request_or_internal`, `IngressRequest::Internal`, the `handle_discover` projection) exists and is unit-tested, but every production transport calls only `crate::shared::parse_request()`, which maps `IngressRequest::Internal → -32601` on every era — so a v2 `server/discover` always returns method-not-found and `dispatch_internal_client_request`/`handle_discover` carry a now-false `#[allow(dead_code)]`.

Wire a LIVE production caller of the internal-dispatch seam on the HTTP transport — the transport a v2 client actually uses (v2 headers only exist on HTTP; D-11). The HTTP POST handler is the only production site that holds the raw request body AND the server together, before `StdioTransport::parse_message` collapses `server/discover` into a parse error. Intercept there via `parse_request_or_internal`, resolve the era from the raw `_meta` + accept-list, and on `era==Era::V2` route to the shared discover projection; on v1 / non-opted-in, return `-32601` (matching the existing public `parse_request` behavior, D-10). Remove the stale `#[allow(dead_code)]`.

Purpose: `server/discover` is the stateless replacement for `initialize`'s capability exchange (D-09) — the phase's headline SC#3. It must actually answer on a v2 connection and expose the `extensions` map, which today it never reaches.

**Scope decision (transport):** This plan delivers `server/discover` end-to-end on the HTTP transport (VERS-04 SC#3 requires it reachable "over at least one real transport"). The stdio actor and the `ProtocolHandler` adapter/wasi transports (adapters.rs, wasi_adapter.rs) receive an already-parsed `TransportMessage::Request` from `parse_message` before dispatch, so routing an internal method through them requires a `TransportMessage`-level internal variant — a semver-sensitive change (`TransportMessage` is a public enum matched in ~30 sites; `cargo-semver-checks` must stay MINOR). That broader wiring is NOT in scope here; if the executor finds it fits within budget it may add it, but the HTTP path MUST work e2e this plan.
