<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → agent-as-server tool | Untrusted tool input (the conversational message) crosses into the adapter's tool handler |
| agent run → downstream connectors | The spawned run invokes connector tools; results are untrusted |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-108-06-01 | Tampering / Input Validation | adapter tool input | mitigate | Tool input validated against the AgentPackage `input_schema` (serde typed); malformed input → tool error, not panic (ASVS V5) |
| T-108-06-02 | Denial of Service | runaway agent run (cost/loops) | mitigate | Run bounded by AgentPackage max_iterations/max_tokens via the `check_limits` pure fn (plan 108-03); fresh run per call bounds per-call state |
| T-108-06-03 | Information Disclosure | error/log surface of the hosted run | mitigate | Handler errors sanitized (host surface already maps to -32603); no secrets in logs; example never prints keys |
| T-108-06-04 | Repudiation | prompt-injection via connector output | accept | Out of SDK scope (host/model policy); rustdoc notes the loop treats tool output as data and takes no privileged action beyond declared tools |
| T-108-06-SC | Tampering | crates (supply chain) | accept | No new package installs (RESEARCH Package Legitimacy Audit) |
</threat_model>
