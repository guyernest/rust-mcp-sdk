<objective>
Build the heart of the crate (AGNT-02, AGNT-03): the pure decision core and the thin async iteration engine that orchestrates the three seams, plus the `EffectTrace` replay substrate and the replay-safety property + digestion fuzz that guarantee determinism.

The engine is a thin `loop {}` that only awaits the three seams; EVERY between-await computation (end-turn detection, result digestion, budget/iteration limits, retry classification) lives in pure, unit-testable, `Serialize`-able functions operating on data types that mirror the reference `IterationResult`/`evaluate_submit_result` shapes (D-05, D-09). No wall-clock, no RNG — iteration counters only. This discipline is exactly what makes the AGNT-03 replay property hold.

Purpose: the pure/replay-safe loop is the durability seam the platform reuses (design §8.1); it is the single most load-bearing contract in the phase.
Output: `iteration/{result,decide,engine}.rs`, `trace.rs` with `EffectTrace` + `ReplaySource`/`ReplayInvoker`, golden-trace fixtures, replay-safety proptest, digestion fuzz.
</objective>
