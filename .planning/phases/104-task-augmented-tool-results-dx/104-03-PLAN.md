Includes a per-tool `suppress_double_wrap_check()` opt-out (D-08). "One local run would have caught it."

Purpose: Make the silent double-wrap failure loud at authoring/CI time, with near-zero false positives.

Empty `content: []` must NOT fire (guard `!arr.is_empty()`). Do NOT full-parse as CallToolResult (D-02). Add a `// Why:` reachability annotation and keep cognitive complexity ≤ 25.
