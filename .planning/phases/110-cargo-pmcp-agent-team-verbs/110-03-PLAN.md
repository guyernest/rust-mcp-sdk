<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| shell → agent dev | User-supplied `--source`/`--endpoint`/`--model` (untrusted) |
| agent dev → LLM endpoint | Outbound HTTP to a user-named endpoint (openai-compat mode) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-110-03-01 | Tampering / EoP | `--endpoint` URL | mitigate | Parse with `url::Url`, reject non-http(s) scheme before use; dev-only source but validated + fails fast (D-03a, Research V5) |
| T-110-03-02 | Information disclosure | LLM API key | mitigate | Key carried as `SecretString` (redacts on Debug); never `println!` a raw key |
| T-110-03-03 | Denial of Service | unreachable default endpoint | mitigate | Catch `CompletionError::Transport`, re-emit actionable `bail!` naming `--endpoint`/`--source fixed`; optional short connect timeout so it fails fast instead of hanging (Pitfall 4) |
</threat_model>
