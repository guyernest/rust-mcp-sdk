| shell → team dev | User-supplied `--serve`/`--llm` flags |
| team dev --serve → network | Binds an HTTP listener exposing team-mcp |
| team dev --llm → LLM endpoint | Outbound HTTP to a user-named endpoint |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-110-04-01 | Information disclosure | `--serve` HTTP listener | mitigate | Reuse the Phase 109 HTTP-first team-mcp binary path (origin/bind controls owned there); default (no `--serve`) stays fully in-process with no listener |
| T-110-04-02 | Tampering / EoP | `--llm` endpoint URL | mitigate | Parse `--llm` with `url::Url`, reject non-http(s) scheme before constructing the source (shares the agent dev V5 control) |
| T-110-04-03 | Denial of Service | default flow | accept | Default flow is offline FixedSource over a tempdir data root — no external dependency, deterministic; low risk |
</threat_model>
