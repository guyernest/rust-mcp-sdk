<objective>
Implement `cargo pmcp package show|capture` (CLI-04). `show` opens a local OCI
image-layout `.pmcp` package, reads the manifest media type to pick the kind (via a
pure, lib-safe `kind::detect_kind` leaf), unpacks the typed manifest, and renders it —
fully offline via `pmcp-package`'s own API (D-04). `capture` is a thin client that
resolves a configured platform target + cached token (reusing `cargo pmcp
configure`/`auth`, D-04a) and POSTs the package; when unconfigured it fails with
actionable guidance, never a panic. Ships the `pmcp-package = "0.1"` caret-pin tripwire
(D-04b). Fills the plan-110-01 stubs. The pure `kind::detect_kind` fn is deliberately a
dependency-light leaf so plan 110-06 can mount it via a lib seam and fuzz it.

Purpose: Portable `.pmcp` packages are inspectable offline and capturable to the platform.
Output: Wired `show`/`capture` handlers + a pure kind-detection leaf + offline show test + unconfigured-capture test + caret-pin tripwire.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| shell → package show | User-supplied filesystem path to an untrusted `.pmcp` package |
| package → filesystem | Reading OCI layout blobs (potentially malicious/tampered) |
| package capture → platform API | Authenticated outbound POST with a cached Bearer token |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-110-05-01 | Tampering | malicious/tampered `.pmcp` package | mitigate | Digest verification runs inside `pmcp_package::unpack_*` (canonical sha256, V6 delegated) — surface verification failures, never bypass; validate the path is a real OCI layout before unpack (V5) |
| T-110-05-02 | Information disclosure | cached Bearer token | mitigate | Reuse the redacting secret handling in the tree; never `println!`/log the token; acceptance-gated grep for token interpolation |
| T-110-05-03 | Denial of Service / confusion | package kind mis-detection | mitigate | Pure, deterministic `kind::detect_kind` (not try-each) with unknown → `None` → clear "unknown kind" error; unit-tested here and fuzzed in 110-06 (Pitfall 3) |
| T-110-05-04 | Spoofing/EoP | pin drift on `pmcp-package` | mitigate | Caret `"0.1"` tripwire test on cargo-pmcp's own Cargo.toml (D-04b); high severity → covered by Task 1 |
| T-110-05-05 | Tampering | platform capture endpoint (out-of-repo) | accept | Endpoint path/payload is platform-owned (A1/Open-Q2); shipped as a named constant + actionable-error path; flagged for platform coordination, does not block the config/auth/error-handling work |
</threat_model>
