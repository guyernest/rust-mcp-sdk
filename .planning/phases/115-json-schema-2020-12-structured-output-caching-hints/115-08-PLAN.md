<objective>
Fence the two invariants this phase establishes but cannot defend by configuration alone: SEP-2106's
no-external-`$ref` property (D-03) and D-12's single-projection-point property.

Purpose: D-03 explicitly rejected "config alone" — *"it is exactly the rot condition the 114-16
instrument exists to catch."* 115-RESEARCH § Finding 2 sharpened WHY: cargo feature unification is
graph-wide, so ONE workspace member, example or dev-dependency declaring `jsonschema` with default
features turns `resolve-http` on for the entire graph and silently converts the measured 60 µs
refusal into a live network fetch. **A behavioural test would still pass** — it would pass *better*,
because the fetch would succeed. Only a `Cargo.toml` scan catches that, and no test in this repo
scans workspace manifests today.

D-12's fence is the sibling: one place to test, one place to rot, and a tripwire asserting no result
type projects independently.

Output: `tests/v2_schema_tripwires.rs` — a new instrument in the proven 114-16 shape (runtime
discovery, comment/literal stripping, two-kind justified allowlists, per-check anti-vacuity).
</objective>
